/**

* Pasta Services: 
    * A pasta services serve como a ponte de comunicação
    * entre o seu painel visual (o front-end em React) e o servidor/banco de dados 
    * (o back-end). Em vez de espalhar requisições e URLs por toda a interface,
    * você centraliza a lógica de rede aqui. Isso deixa os componentes mais
    * limpos e facilita muito a manutenção caso a URL da API mude no futuro.


* Arquivo api.js:
    * Configuração central da API,
    * Cria e exporta uma instância padronizada do Axios com a URL base do servidor 
    * (pegando das variáveis de ambiente ou usando localhost) e cabeçalhos padrão. 
    * Todos os outros serviços utilizam essa instância para fazer requisições.
 
* Arquivo cadastro.js:
    * Serviço de Cadastro,
    * Envia os dados do formulário de registro (novo usuário) via método POST 
    * para a rota "/api/auth/cadastrar" do back-end. Captura a resposta de sucesso 
    * ou repassa os erros (como e-mail já existente) para serem tratados na interface.

* Arquivo login.js:
    * Serviço de Login:
    * Envia as credenciais do usuário via método POST para a rota "/api/auth/login".
    * Retorna os dados da sessão (como o token JWT) em caso de sucesso ou 
    * lança um erro (como senha incorreta) para o componente de formulário exibir.
 
 */
